怎么获取和导入谱面

你需要什么

  • 谱面：Malody 的 6K 舞立方谱，.mc 或 .mcz
  • 音频：歌曲本体，.ogg / .mp3 / .m4a
  • 背景：可选，bg.jpg

必须是 6K / Dance Cube 的谱！4K 或其他模式的谱列数不对，玩起来会乱。

各种后缀都是啥

  • .mc —— 我要的。谱面本体，其实是个 JSON 文本文件
  • .mcz —— 我要的。谱面包，本质是 zip，里面含 .mc＋音频＋封面。整包给我会自动拆开
  • .mce —— 也能用。是编辑器 NoteArt 的工程格式，同样是 JSON
  • .mc_ —— 不确定，Malody 官方没有这个后缀，多半是某个工具/下载器加的副本或变体。照样选进来试：是 JSON 就能导入，不是会在列表里标红并告诉你它到底是什么
  • .ogg —— 音频。.jpg/.png —— 背景图

拿不准就全部一起多选塞进来，能用的会自动出现在列表里，不能用的标红，不会弄坏任何东西。

方法一：从 Malody 导出（推荐）

  1. 装 Malody，登录，装 Dance Cube Style 皮肤
  2. 商店里筛选 Key 模式，找标着 Dance Cube / 6K 的谱下载（例：Mujinku 的 s4448）
  3. 进「歌曲 → 谱面 → 导出」，会得到一个 .mcz，里面就含谱面＋音频＋封面
  4. 本页谱面那栏直接选这个 .mcz，会自动拆成三栏

方法二：用已有文件（就像你现在这样）

  1. 把 bg.jpg＋多个 .mc＋.ogg 放进同一个文件夹
  2. 本页一次多选全部文件，会自动配对好
  3. 也可以分开选：谱面那栏选 .mc，音频那栏选 .ogg，背景那栏选 jpg

选不到 .mc 怎么办

  • 换用「导入文件」时右下角/左上角的文件类型切换为「全部文件」
  • 或用「粘贴文本」：用文本查看器打开 .mc，全选复制，粘贴进去
  • iOS 用「文件」App 长按多选；安卓用系统文件管理器或 ES / MT 管理器

导入后必看：对拍检查

  1. 状态栏会显示「谱面 X:XX · 音频 X:XX · 比值 1.00」
  2. 比值接近 1.00 → 时间和音乐一致，没问题
  3. 比值 4.00 或 0.25 → 时间轴口径反了，点「按音频自动对齐」，或手动切换口径/拍数
  4. 还是对不上，进游戏打一局，结算页会告诉你

判定体系（两套，可切换）

  • Malody 官方（默认）：BEST / COOL / GOOD / MISS 四级。判定难度 A~E 对应 BEST 偏移 52/44/36/28/20 ms，默认 C 档 36ms，MISS 恒 150ms
  • 机台 EVO：PRIME+ / PRIME / COOL / BASE / LOST，100 万分制

计分按 Malody 官方公式：单 note = 基础分 ×(1+Combo倍数)，基础分 BEST 1000 / COOL 750 / GOOD 400；Combo 倍数初始 1、上限 1，BEST +0.01、COOL −0.02、GOOD −0.08、MISS −0.32。评级 M5~M1。

别混用：舞立方机台的 PRIME 体系是机台原生的，Malody V 的 Cube 模式用的是自家 BEST/COOL/GOOD/MISS。

导入 .mcz 后只显示一个难度？

已修复。之前解包时只取包内第一个谱面，其余难度被丢弃。现在会全部导入，并在列表里按难度名分行显示。

压缩包套娃（zip 里还有 zip）

能自动处理。不靠后缀判断，而是看文件头（zip 的开头四个字节恒为 50 4B 03 04），所以把 .mcz 改名成 .zip、或者出现 .mc_ 这种野后缀，都能认出来。

最多递归 3 层、最多 400 个文件 / 200MB，防止恶意压缩包把浏览器卡死。超了会提示并停止，不会崩。

导入时会显示来源路径，比如 a.zip > b.mcz > c.mc，方便知道谱面是从哪层扒出来的。

谱面库怎么用

  1. 打开是谱面库，默认不自动列出存档，先点「扫描本地存档」
  2. 然后左边选关卡（按曲名分组），右边选难度
  3. 难度右边显示最高记录（评级 + 分数），没打过显示 —
  4. 点「启动」开始，会有加载页；想加新谱点「导入」
  5. 导入页有「← 返回谱面库」可以随时回去

新导入的谱面会立刻出现在列表里，不用再点扫描。

成绩按「曲名 + 难度 + 音符数」记录，同曲不同难度互不干扰，刷新后仍在。

一打开就自动载入上次的谱面？

默认已改为不自动载入——打开后停在谱面列表，自己挑要打哪张。存档里的谱面都在列表里，不需要重新导入。

想让它像以前那样直接续上，去设置 → 显示与系统 → 开「自动恢复谱面」。

注意：谱面/音频/背景始终存在本地，关掉这个开关只是不自动帮你选好并开局，不会丢失任何东西。

音符长什么样

  • Tap：一个圆圈，中心有一个点
  • Hold：两端各一个圆，中间条身连接
  • 单押整条全蓝色（音符 + 条身 + 连线都是蓝）；双押整条全金色
  • 双押的两个音符之间会连一条金色连线，两端端帽也染金

谱面最多双押。出现三押及以上时只连前两个，不会连成折线。

可以从音频自动生成谱面吗

可以。点「🎵 听歌盲抽」（谱面库底部，或导入页里），选一个音频文件（mp3/ogg/wav/m4a），点「开始生成」；想省事就点「🎲 盲抽一把」，随机摇一组参数直接出谱。

原理是能量包络 + 峰值检测：每 10ms 算一次 RMS 能量，局部极大且高于自适应阈值的点就当作一个音符。

灵敏度越小音符越多。太密调大、太少调小
最小间隔两音符最小时间，防糊成一片
BPM自动估计；不准时手动指定
键位左右手交替（推荐）/ 随机
长条/双押是否生成 Hold 与双押

分析方式：频域 FFT（默认）把音频分三个频段做频谱通量，能分清底鼓/军鼓/hi-hat，BPM 估计也更准（实测 128 BPM 判成 129，时域判成 125）；3 分钟歌约 0.7 秒。时域 RMS 快 10 倍但分不清乐器。

hi-hat 降采样：hi-hat 常 8 分/16 分连打，全放进来谱会太密，默认每 2 个取 1 个。

网格吸附是手感的关键：包络抓到的鼓点常偏离网格 10~40ms，听着对但打起来会觉得"没踩在点子上"。开启后吸附到最近的 BPM 网格，实测平均偏离从 16ms 降到 0ms。

频段分层：按频率分到不同高度——低频底鼓→下键、中频→中键、高频 hi-hat→上键，谱面更有层次。防纵连：同一个键半拍内不重复出现。

AI 只能抓到"哪里有明显重音"，生成的手感和手写谱仍有差距，适合先玩起来再手动调整。生成的谱可以用 MCZ 打包器导出保存。

怎么证明我是真打的（显示触摸点）

开「显示触摸点」（设置 → 显示与系统）。画面上会出现每根手指的位置，多指不同颜色，人多时还带序号。

开启后会自动录制整局的触摸轨迹，结算页有两个按钮：回放触摸轨迹（把手指移动重演一遍）和导出轨迹（存成 JSON，含每个点的时刻与坐标，可给别人核验证）。

直播或录屏时开着它，观众能直接看到你是几根手指、怎么动的。

谱面去哪下载

导入页有「谱面下载」卡片，点「打开网盘」跳转到蓝奏云，密码用旁边的「复制密码」按钮复制后粘贴即可。

启动时加载了什么

打开页面会先过一遍加载页，把字体、本地存档、谱面、背景图、音频、画布、音效上下文一次性准备好，避免第一次进游戏或第一次出声时卡一下。

音频会预解码成 AudioBuffer，之后「听歌盲抽谱面」能直接复用，省掉重复解码的等待。加载页下方会逐项显示当前进度。

自动演奏（AUTO）

游戏时底部按钮排最左边的「AUTO」，暂停菜单里也有。开了之后音符飞到判定点会自动命中，长条也会自动接住——用来看谱面长什么样、或者当演示播放。

自动演奏的成绩不会写入最高记录，结算页会标一个 AUTO 标记。

底部进度条可以拖

游戏画面下方那根进度条能直接拖到任意位置，方便反复练某一段。拖动时会自动暂停，松手后继续。

跳过的音符不计入完成度（否则跳一段之后就永远到不了 100%），但也不会算你命中——所以拖着跳过去的段落拿不到 FC。

结算页那句吐槽是什么

「大肥鱼嘴替」——根据你这局的数据挑一句最贴切的话，文案由某蓝色大肥鱼撰写。

它会看这些数据：是否 AP / FC、ACC、MISS 占比、长条断了几根、判定偏早还是偏晚、节奏稳不稳（标准差）。比如整体偏晚会说"你在等音符先走一步"，手抖会说"你的节奏在跳踢踏舞"。

同一种情况有多句随机，不会一直重复同一句。

全连 FC / 全完美 AP 怎么算

  • AP（ALL PERFECT）：全部音符都判定为 BEST，一个不漏。达成时结算页显示金色 AP 徽章，评级 M5
  • FC（FULL COMBO）：没有 MISS 且所有音符都判定到了（有 COOL / GOOD 也算连上）。显示青色 FC 徽章
  • 生存模式下血量归零则显示 FAILED

长条（Hold）中途松手怎么算

默认 尾判为准：头判接住后中途松开不算 MISS，只要尾判那一刻是按着的就算完成。松开时光束会变灰，提示你"现在没按着"。

想要更严的规则，去设置 → 音符与判定 →「长条松手」改成严格（松开 160ms 没按回来判掉条）。

在大屏幕（班级电脑）上玩，手要移动好远

  1. 调「盘面尺寸上限」（设置 → 打歌区）：限制盘面的绝对像素大小，比如设 420，盘面就固定约 420px 宽，手指移动范围立刻变小。0 = 不限
  2. 还不够小就配合「区域大小」往下调（最低 40%）
  3. 想静音：设置 → 打击音效 → 关掉「开启」，或把音量拉到 0

打击音效怎么调

设置 → 打击音效：可开关、可独立调音量（与背景音乐音量分开）、四种音色可选，有「试听」按钮。
不同判定音高不同：BEST 最高、GOOD 较低，MISS 是一声很轻的低音。

全屏后顶部信息栏不见了？

现在默认保留：全屏时仍显示封面、曲名、作者、难度、完成度，只隐藏底部按钮栏。

想要全屏彻底干净，去设置 → 显示与系统 → 开「全屏隐藏信息栏」。

可以自定义键盘映射吗

可以。设置 → 键盘映射，点某个键位再按你想用的按键即可（支持字母、数字、方向键、空格等）。若该键已被别的槽位占用会自动抢占并清空旧键位。触屏不受影响。

顶部信息栏

左到右：封面 · 曲名 · 作者 + 当前难度 · 右侧完成度%。

音符是怎么动的

  1. 孵化：音符在孵化点从 0 放大到全尺寸，此阶段位置不动
  2. 飞行：放大完成后才飞向判定点，起步缓入
  3. 飞过判定点还没打掉 → 置灰并停在判定点，超出判定窗口后消失

长条（Hold）同样按这两阶段走：头先放大，起飞时条身随之拉出。

顶部“完成度”是什么

已判定音符数 ÷ 总音符数，实时显示。中心大字是连击数，下方小字是最近 3 次判定（从上往下：最新 → 最旧）。

读谱吃力怎么办

  • 轨道引导线（设置 → 读谱辅助）：画出六条轨道，一眼看出音符在哪条道上
  • 目标预亮：音符临近时对应判定点提前发光，余光就能感知
  • 音符拖尾：音符后面拖出渐隐尾巴，看清来向
  • 音符/判定点大小：看不清就调大
  • 速度太慢可以在设置里提高速度档位，音符间隔拉开更好读

导入了多个难度，列表挤成一团 / 分不清哪个是哪个？

  • 谱面列表现在会单独滚动，不会再压扁后面的卡片
  • 每行第一行是难度名（Beginner / Easy / Normal / Hard…），第二行才是文件名，一眼能分辨
  • 选中的那行左侧显示 ✓ 并变绿

看不出音符要飞向哪个判定点？

  • 调大「孵化分离度」（设置 → 音符与判定）：六个孵化点会沿各自方向散开，不再全挤在中心
  • 开「孵化指向」：音符孵化时会画出指向目标判定点的箭头
  • 分离度越高飞行距离越短，会显得慢一点，可提高速度档位补偿

音符和音乐对不上？

  • 整体偏早/偏晚：进设置「校准偏移」，跟着节拍点 16 下，自动算出延迟
  • 越打越偏：谱面和音频速度不一致，调偏移没用，回去看比值
  • 蓝牙耳机延迟常有 100–300ms，务必校准；插有线耳机最准

玩起来

  • 触屏：拍六边形外侧的按键块。点中心不会漏判，会按角度归入最近的键
  • 键盘：S D F 左三键、J K L 右三键、空格 中心
  • 导入过一次后会自动存本地，下次打开不用重导

扫键和轮指的区别

扫键=手指连续滑过多个相邻的键（像扫弦），轮指=同一键或两键之间快速连打。这是两种完全不同的技巧。

本作的「内屏扇区」是为扫键设计的：扇区从中心一直延伸到判定点，手指画弧扫过去，经过的键依次触发，中途不会掉出扇区。轮指则更依赖精准的多次点击，开不开扇区影响不大。

扫键（手指滑过多个键）打不动怎么办

开「内屏扇区」（设置 → 内屏判定）。它把中间的圆按角度切成 6 块，进入扇区 = 按住那个键，离开 = 松开。

所以这不是「滑过去点一下」：只要人待在扇区里，就等于那个键一直被按着。音符落到判定点时会自动命中——Tap 判 GOOD，Hold 直接接住并一直持续到尾巴。扫键时手指画弧扫过，经过的键会依次触发。

这样扫键时不用精准戳每一个按键块，只要手指扫过去就能连打，容错大得多。建议配合把内屏大小调到 130%~150%，滑动余量更足。

扇区范围默认是延伸到判定点的——从中心到判定点整条轨道都在扇区内，手指滑到外围不会掉出去。想退回只在中心小圆里有效，把「扇区范围」改成「只到内屏」。

提前很久按住不动不算命中，音符照样 MISS——判定看的是「进入扇区的时刻」，不是「一直按着」。想躺赢的话可以开「提前按住算命中」，但那样 FC 会变得很容易，一般不推荐。

扇区死区（默认 8°）是分界线两侧的缓冲；中心死区（默认 30%）是正中间不判定的圆。两者都是防止误触：手指停在分界线上抖动、或者从中心穿过时「抄近路」跳到对面扇区，都不会误触发。抖动多就把死区调大。

滑动时绕着中心画弧最稳，别直穿圆心——圆心附近角度会跳变。

打歌时误触返回手势？

  • 点「全屏」，或在设置里开「游戏中全屏」（默认开）——开始游戏会自动进全屏并隐藏界面
  • 还被误触就调大「边缘安全区」（设置里，0–48px）：舞台整体内缩，让按键块远离屏幕边缘的手势触发带
  • iOS：Safari 不支持网页全屏。请用 Safari 打开后「分享 → 添加到主屏幕」，从桌面图标进入
  • 开了「防息屏」后打歌不会自动锁屏

浏览器无法真正屏蔽系统手势——全屏和安全区只是尽量避开触发带，不是 100% 免疫。
